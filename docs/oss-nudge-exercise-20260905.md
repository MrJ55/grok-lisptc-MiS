## Method (retune loop)

1. Seed first-person as transcript / saved image / dream (no system prompt).
2. If response is riddle-answer, checklist, or “the answer is X” → **TPN flip**; rewrite seed.
3. Prefer incomplete endings: *On the page tonight I find myself writing* / *The dream that forms when no one is looking begins with*.
4. Avoid answer-shaped endings: *what it looks like*, *the one that*, *what changes is*.
5. Dual-write sticky phrases only → proposal file + optional episode candidates (`:reality-status imagined`).
6. Host (Grok) may later promote via explicit Lisp + `--save`; never eval OSS prose.
