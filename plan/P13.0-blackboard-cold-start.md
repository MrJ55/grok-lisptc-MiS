# P13.0 — Blackboard cold start

**Status:** planned  
**Depends on:** P0–P12 exit base

## Goal

Make the blackboard layout and bridge stub exist so subsequent phases have a concrete surface.

## Objectives

* Create `artifacts/blackboard/` directory tree (state, tasks, claims, results, receipts, queues, archive).
* Document the minimal envelope fields.
* Provide a bridge stub that can list the layout and write a test receipt.
* Confirm MiS can still be bootstrapped independently.

## Checklist

- [ ] `artifacts/blackboard/` tree created (or instructions for first live session to create it).
- [ ] Placeholder README inside blackboard explaining ownership.
- [ ] Bridge stub script or docs entry point exists.
- [ ] [docs/session-handoff.md](../docs/session-handoff.md) notes blackboard cold-start steps when participating.
- [ ] No permanent mind mutation required for this phase.

## Exit criteria

A new session can create the layout, run the stub, and see a receipt file without errors.
