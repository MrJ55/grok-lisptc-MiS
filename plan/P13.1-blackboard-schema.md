# P13.1 — Blackboard schema

**Status:** planned  
**Depends on:** P13.0  
**Normative:** [docs/blackboard-schema.md](../docs/blackboard-schema.md) **v0.2**

## Goal

Versioned envelopes so every peer mind and the bridge speak the same language. Context packets required for Grok-class jobs; author lineage on every write.

## Required kinds

Task, claim, result, receipt, injection-request, busy-lease, state / high-water.

## Tasks

- [x] Normative schema v0.2 in docs (context packet, `author-role`, `author-mind-id`).
- [ ] Bridge validates required fields on write.
- [ ] File naming: `T-YYYYMMDD-HHMMSS-<role>-<seq>.json` (or UUID) documented and used in tests.
- [ ] JSON primary; S-expr optional inside payload fields.
- [ ] Accept 0.1 reads; new writes 0.2.
- [ ] Test write of each kind against documented fields.

## Exit criteria

Schema doc is source of truth; automated or scripted validation of sample envelopes; missing author fields rejected.
