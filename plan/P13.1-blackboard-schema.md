# P13.1 — Blackboard schema

**Status:** planned  
**Depends on:** P13.0

## Goal

Versioned, minimal envelope schemas so every role and the bridge speak the same language. Normative text lives in [docs/blackboard-schema.md](../docs/blackboard-schema.md).

## Required kinds

Task, claim, result, receipt, injection-request, busy-lease, state snapshot / high-water mark.

## Tasks

- [ ] Keep `docs/blackboard-schema.md` as source of truth.
- [ ] File naming convention (`T-YYYYMMDD-HHMMSS-role-seq.json` or equivalent).
- [ ] JSON preferred for bridge; S-expr optional for mind-facing payloads.
- [ ] Schema version field (`schema-version: "0.1"`).

## Exit criteria

Schema doc current; test write of each kind validates against documented fields.
