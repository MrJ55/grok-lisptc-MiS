## Goal

Establish the trust base: pin the upstream runtime, formalize provenance, separate content trust classes, add reality-status to every cognitive item, enforce capability governance, and make every durable mutation transactional, recoverable, and provenance-complete.

This phase is the prerequisite for any expansion of autonomous cognition (P7–P11). Do not start P7+ until P0.1 exit criteria pass.

## Objective

1. **Upstream lock** — `UPSTREAM.lock.json` with full commit SHA, content hashes, capability profile (done).
2. **Hash verification** — `scripts/verify-upstream.sh` (done).
3. **Trust classes** — five-class taxonomy (untrusted / candidate / approved / derived / immutable) with promotion flow.
4. **Reality-status field** — every episode, chapter, and self-schema claim carries `:reality-status` from the enum `observed | reported | inferred | hypothesized | imagined | planned | simulated | retracted` (partially seeded in mind-image).
5. **Compatibility manifest** — `*mind-manifest*` as the first form in `mind-image.ptc`; bridge validates it before evaluating the rest.
6. **Capability governance** — deny-by-default evaluator; explicit capability loading with declared profile.
7. **Transactional persistence** — prepare → validate → temp write → hash → atomic rename → verify reload; audit journal + last-known-good checkpoint (atomic append done).
8. **Operation event log** — every capability invocation recorded.
9. **Threat model** — `docs/threat-model.md` documenting attack surfaces.
